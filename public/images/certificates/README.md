# Certificate Images

## Add Your Certificate Images Here

Save your certificate images with these names:

1. `techwaves-2025.jpg` - NIBM TechWaves 2025 certificate
2. `generative-ai-business.jpg` - Generative AI for Business Leaders
3. `microsoft-security.jpg` - Microsoft Security Essentials
4. `azure-ai-essentials.jpg` - Azure AI Essentials
5. `sustainability-foundations.jpg` - Sustainability Foundations

## How to Add Images:

1. Take screenshots or save your certificate images
2. Rename them according to the list above
3. Copy them to this folder: `public/images/certificates/`
4. Restart your React app: `npm start`

## Image Requirements:

- Format: JPG, PNG
- Recommended size: 1200x800 pixels or similar aspect ratio
- Keep file size under 500KB for faster loading

Your certificates will appear in the new "Certificates & Achievements" section!
